Média Aritmética (μ ou x̄)

É a soma de todos os valores dividida pelo número total de elementos. Representa a distribuição igualitária caso todos recebessem o mesmo.

Média = (x₁ + x₂ + ... + xₙ) / n
🛶

Mediana

O número exatamente no meio quando ordenamos os dados do menor para o maior. É resistente a valores extremos (outliers)!

Em [2, 3, 5, 8, 9] ➔ Mediana = 5
🪷

Moda

O valor que aparece com maior frequência no conjunto de dados. Se nenhum se repete, dizemos que é amodal.

Em [4, 7, 7, 7, 9] ➔ Moda = 7
📏

Amplitude & Desvio Padrão (σ)

A amplitude é a distância entre o maior e o menor valor. O Desvio Padrão mede o quanto os dados se afastam da média: quanto menor, mais homogêneo e previsível é o grupo!

Desvio Padrão = √[ Σ(xᵢ - μ)² / n ]
🎲

Probabilidade P(E)

A chance de um evento acontecer, variando de 0 (impossível) a 1 (100% de certeza). É calculada dividindo os casos favoráveis pelos casos possíveis.

P = Casos Favoráveis / Casos Possíveis
🔔

Distribuição Normal (Curva Gaussiana)

Muitas coisas na natureza (peso das capivaras, altura dos ipês) formam o formato de sino: a maioria fica perto da média, e valores extremos são raros.
